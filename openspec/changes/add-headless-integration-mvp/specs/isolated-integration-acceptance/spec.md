## Purpose

用合成数据和固定版本的客户端、服务端及外部馆长集成证明首版可用于隔离环境双向同步，明确区分源码证据、自动测试和业务验收，防止把局部成功误报为端到端交付。

## ADDED Requirements

### Requirement: 固定版本与能力证据

验收报告 SHALL 记录 fork 提交、上游提交、测试服务端提交或不可变镜像标识、运行时、配置范围和资源上限，并逐项给出修改、删除、重命名、Ack、分页与历史保留的能力证据。源码比较 MUST 与运行验证分开标注。

按用户 2026-09-17 明确边界，验收 SHALL 区分 Node 适配缺陷与官方基线已有问题。上游缺少原子删除/重命名条件或独立服务身份时，保留特征测试与限制说明，不要求修复上游、不据此否决已通过的普通双向操作，也不将这些更强保证标为通过。

#### Scenario: 仅有服务端源码参考
- **WHEN** 某提交仅被阅读或比较而没有实际运行集成测试
- **THEN** 报告标注未完成兼容验收，不把该提交列为已验证支持版本

### Requirement: 双宿主互操作和故障矩阵

首版验收 SHALL 包括声明支持范围内实际 Obsidian 插件与 Node 客户端的双向操作、完整内容清单核对和稳定后的幂等空同步；同时覆盖断线、Ack 丢失、重复和乱序事件、落盘和提交之间崩溃、离线删除、历史过期、路径逃逸、所有权冲突及资源失败。采样哈希 MUST 不能代替完整字节或完整摘要验收。

#### Scenario: 插件与 Node 往返修改
- **WHEN** 使用合成笔记和附件依次执行两端修改、删除及重命名
- **THEN** 受支持的无冲突操作得到相同最终内容和路径，并在下一轮无变化同步中保持不变

#### Scenario: 故障注入后的真实结果
- **WHEN** 在发送、确认、文件替换或状态提交边界终止并重启客户端
- **THEN** 恢复后内容收敛或进入明确安全阻塞，未确认操作不被记为成功，保留数据不丢失

### Requirement: 身份错配和本地竞态专项验收

验收 SHALL 覆盖同一状态目录切换配置端点、认证主体、Vault 名称及可取得的标识、本地目录，以及原路径目录被替换和同主体凭据轮换；不可取得的上游身份记录为未覆盖，不虚构服务身份。并发测试 MUST 在本地版本复核之后、替换之前设置确定性屏障，让独立进程提交受控写入，证明互斥范围，而非仅做随机并发或两个同步进程争锁测试。

#### Scenario: 身份错配携带待删除操作

- **WHEN** 对包含待删除操作的状态变更任一目标身份后启动
- **THEN** 观察到明确拒绝、新目标和本地文件无副作用、旧状态保留；同主体凭据轮换且绑定一致的对照用例则可以恢复

#### Scenario: 在精确竞态窗口提交 Bot 写入

- **WHEN** 远端应用或冲突解决停在复核后的屏障，Bot 提交修改或重命名
- **THEN** Bot 请求不能穿过屏障直接改文件，释放屏障后根据新版本成功或明确拒绝，双方内容均不被静默丢弃

### Requirement: 已接受的上游采样盲区限制

按用户 2026-09-16 明确决策，首版 SHALL 将大附件采样盲区记录为已知上游限制，专项修复、静默远端变化的周期审计和三端收敛验收等待上游正式稳定版修复，不再作为首版交付的必需条件。已有 20 MiB / 偏移 6 MiB 的运行证据 MUST 保留，延期不等于已修复或测试通过；其他双向操作、故障恢复及 Hermes 验收要求继续适用。

#### Scenario: 原盲区用例仍未收敛

- **WHEN** 当前稳定版仍无法经既有 WS 路径发布采样区外的修改
- **THEN** 报告标为用户接受的已知限制，继续声明范围内的验收，不声称该用例成功，也不以此暂停整个 apply

#### Scenario: 上游发布相关稳定版修复

- **WHEN** 后续正式稳定版包含相关修复并被选择为升级候选
- **THEN** 重新评估原向量和实际插件/服务端/Node 三端收敛，再决定恢复专项验收及扩大支持声明

### Requirement: Hermes 验收使用业务回执

完整首版验收 SHALL 在外部 Hermes Ops 隔离环境中证明 Bot 与 Obsidian 双向修改、馆长有效决策应用、陈旧决策拒绝及重启恢复，并保留不含私人内容的业务成功回执。Bot 必须经受控入口修改本地文件，并验证绕过入口的直接写入被权限或等价约束阻止。确定性测试 resolver MUST 不能替代馆长集成验收。

#### Scenario: 客户端测试通过但馆长尚未接入
- **WHEN** 自动测试和通用冲突契约测试通过，但没有 Hermes 业务回执
- **THEN** 仅标记客户端验证完成，完整隔离集成验收保持待完成

### Requirement: 隔离验收边界

本次验收 SHALL 使用合成数据、独立 Vault 和独立状态目录，不修改生产同步程序；候选产物 MUST 不经继承的插件 release 或 mirror 流程发布为 headless 产品。

#### Scenario: 完成隔离验收
- **WHEN** 所有隔离验收条件通过
- **THEN** 交付版本、范围、限制和回执，生产切换仍属于单独的 Ops 部署，不自动触发发布或切换
